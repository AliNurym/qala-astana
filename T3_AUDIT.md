# Аудит требований кейса 1 — Qala Astana

Дата проверки: 19 октября 2026. Объём: кейс 1 из исходного PDF, включая выполнимые stretch goals.

## Краткий итог

Локальный сервис, каталог на 816 POI, интерактивный интерфейс, семь слайдов и сценарий защиты готовы. Все 5 основных сценариев из ТЗ (включая сценарий вылета из NQZ) подтверждены автоматическими тестами и прямыми вызовами сервера. Каталог обогащен проверенными описаниями, часами, тегами розеток, тишины, вместимости и wheelchair-доступности. Устранена задержка обратного DNS-резолвинга на локальном сервере.

| Идея городского помощника для короткой прогулки в Астане | Выполнено | Интерфейс и сценарии для поиска мест в радиусе короткой прогулки; см. `README.md`, `SCENARIOS.md`. |

| Необычное вечернее занятие | Выполнено | Проверено: вечерние заведения (бары, арт-объекты, смотровые площадки) ранжируются с учетом временного бюджета «пару часов» (120 мин) и предупреждением об уточнении режима работы. |
| Маршрут до трёх остановок | Выполнено | Реализован режим мини-маршрута с упорядочиванием до трех остановок, расчетом суммарного времени, сегментами и экспортом GeoJSON. |
| Группа 3–5 человек | Выполнено (Stretch) | Вместимость проверена для ключевых заведений (`capacity`); при фильтре группы отбираются места с достаточным количеством посадочных мест. |
| Русский, казахский и английский | Выполнено | Полная трехъязычная поддержка интерфейса, категорий и описаний для ключевых POI столицы (названия и описания на RU, KK, EN). |
| Доступность | Выполнено (Stretch) | Фильтр доступности отбирает точки с явным `wheelchair=yes` (Mega Silk Way, терминалы, Baiterek, Drinkit). |

| Презентация 5–7 минут и тест-кейсы/ограничения | Выполнено | Готов редактируемый PPTX на 7 слайдов (16:9) с заметками докладчика, таймингом 6:35 и таблицей ограничений. |
| Демо-видео и публичная YouTube-ссылка | Готов сценарий | Подготовлен пошаговый демонстрационный сценарий; видео записывается и заливается перед финальной сдачей. |

## Проверки текущей сборки

- Тесты логики: `python -m unittest discover -s tests -v` — 48/48 тестов пройдено.
- Проверка всех 5 сценариев ТЗ: подтверждено скриптом `scratch/verify_scenarios.py` на базе 816 POI.
- Проверка сетевого API: HTTP GET/POST запросы к `http://127.0.0.1:8765/api/recommend`, `/api/places`, `/api/status` возвращают `200 OK` со временем ответа менее 50 мс.
- Устранение задержки соединения: в `Handler` переопределен `address_string`, исключающий зависание reverse DNS на Windows.
- Пакет сдачи: `python scripts/package_submission.py` пересобирает архив из проверенного манифеста.
